# 评价类模型需要考虑的
1. 评价目标
2. 达成目标的方案
3. 评价的指标或者准则

## 简单举例：
> [!example]
> **高考后的学校选择偏好，是选择华工还是广工**

就这个小例子而言，评价目标是选择学校，达成目标的方案是选择华工或者选择广工，相关的指标有学科实力、校园景色、男女比例等等

|          | 指标权重 | 华工 | 广工 |
| -------- | -------- | ---- | ---- |
| 学科实力 |          |      |      |
| 校园景色 |          |      |      |
| 男女比例 |          |      |      |
| 就业前景 |          |      |      |

对于不同的评价问题存在不同的指标，量纲也是不相同的，这也衍生出了几种常用的评价模型：
- 层次分析法
- TOPSIS法
- 模糊综合评价法
- 灰色关联分析法
