# 优劣解距离法(TOPSIS)
---

# 1. 层次分析法的缺陷
层次分析法有一定缺陷，它的主观性比较大，一般需要专家来进行打分（我们自己也不算专家），而且指标和方案过多时，判断矩阵和一致矩阵可能会出现较大差异（毕竟打分不可能完全遵循那个乘法关系），有具体数据时，再主观打分也不合适

### 举个例子：
成绩综合评价问题

| 姓名     | 高代成绩 | 竞赛得分 | 违纪次数 |
| -------- | -------- | -------- | -------- |
| 小明同学 | 80       | 90       | 2        |
| H.H      | 90       | 85       | 1        |
| Struck   | 89       | 80       | 0        |

-----------------------------------------------

# 2. TOPSIS 算法的核心思想
> [!Note] TOPSIS 算法
> 根据已有数据 --> 构建所有方案组成的系统中的最优解和最劣解 --> 评价系统中任何一个方案距离最优解和最劣解的综合距离。
> 如果一个方案距离理想最优解越近，距离最劣解越远，我们就有理由认为这个方案更好

----------------------------------------------

# 3. 原数据处理 - 正向化
有些指标的数据越大越好，有些则是越小越好，有些又是中间某个值或者某段区间最好，一个好的方法是对所有数据都进行**正向化处理**，将数据全部转换成**极大型指标数据**

## 3.1 极小型指标
可以用 $\hat{x}_i=\max -x_i$ 将其转化为极大型

#### 例子（综评）：

| 姓名     | 高代成绩 | 竞赛得分 | 违纪次数 | 正向化的违纪次数 |
| -------- | -------- | -------- | -------- | ---------------- |
| 小明同学 | 80       | 90       | 2        | 0                |
| H.H      | 90       | 85       | 1        | 1                |
| Struck   | 89       | 80       | 0        | 2                |
| 指标类型 | 极大型   | 极大型   | 极小型   | 极大型           |

## 3.2 中间型指标
如果其最佳数值是 $x_{best}$
我们可以取 
$$M=\max \left\{ \left| x_i-x_{best} \right| \right\}$$
然后按照
$$\hat{x}_i=1-\frac{x_i-x_{best}}{M}$$
这样子也能转化为极大型

#### 例子（PH值）：
$x_{best}=7$
$M=\max \left\{ |6-7|,|7-7|,|8-7|,|9-7| \right\} =2$

| PH值（转换前） | PH值（转换后） |
| -------------- | -------------- |
| 6              | $\frac{1}{2}$  |
| 7              | $1$            |
| 8              | $\frac{1}{2}$  |
| 9              | $0$            |

## 3.3 区间型指标
如果其最佳区间是 $\left[ a,b \right]$
我们取
$$M=\max \left\{ a-\min \left\{ x_i \right\} ,\max \left\{ x_i \right\} -b \right\} $$
然后按照
$$\hat{x}_i=\begin{cases}
	1-\frac{a-x_i}{M},x_i<a\\
	1,a<x_i<b\\
	1-\frac{x_i-b}{M},x_i>b\\
\end{cases}$$

#### 例子（体温）：
$a=36$，$b=37$
$M=\max \left\{ 36-35.2,38.4-37 \right\}=1.4$

| 体温（转换前） | 体温（转换后） |
| -------------- | -------------- |
| 35.2           | 0.4286         |
| 35.8           | 0.8571         |
| 36.6           | 1              |
| 37.1           | 0.9286         |
| 38.4           | 0              |

到此，我们对所有的指标都进行了**正向化**

----------------

# 4. 原数据处理 - 标准化
此步骤为了消除不同量纲的影响，对已经正向化的数据进行标准化
我们记标准化的矩阵为 $Z$，其中
$$z_{ij}=\frac{x_{ij}}{\sqrt{\sum\limits_{i=1}^n{x_{ij}^{2}}}}$$
也就是
$$z_{ij}=\frac{\text{每一个元素}}{\sqrt{\text{其所在列元素的平方和}}}$$

我们用 $z_i$ 来表示第$i$个方案，假设有$n$个待评价的方案、$m$个指标，
此时$z_i=\left(z_{i1},z_{i2},\cdots,z_{im}\right)$，$n$个向量构成标准化矩阵$Z$

最后能得到一个标准化矩阵$Z$
$$Z=\left( \begin{matrix}
	z_{11}&		z_{12}&		\cdots&		z_{1m}\\
	z_{21}&		z_{22}&		\cdots&		z_{2m}\\
	\vdots&		\vdots&		\ddots&		\vdots\\
	z_{n1}&		z_{n2}&		\cdots&		z_{nm}\\
\end{matrix} \right) $$

--------------------

# 5. 计算得分
进行了正向化处理和标准化处理的评分矩阵，数据全部都是极大型数据，可以进行得分计算

计算公式：

$$\frac{z\text{与}z^-\text{的距离}}{z\text{与}z^+\text{的距离}+z\text{与}z^-\text{的距离}}$$
其中，$z^+$为最优解，$z^-$为最劣解

具体而言，对于第$i$个方案$z_i$：
它与最优解的距离
$$d_{i}^{+}=\sqrt{\sum_{j=1}^m{\left( Z_{j}^{+}-z_{ij} \right) ^2}}$$
它与最劣解的距离
$$d_{i}^{-}=\sqrt{\sum_{j=1}^m{\left( Z_{j}^{-}-z_{ij} \right) ^2}}$$
其中，$Z_{j}^{+}$是第$j$列的最优解，$Z_{j}^{-}$是第$j$列的最劣解


则最后得分为 $S_i$：
$$S_i=\frac{d_{i}^{-}}{d_{i}^{+}+d_{i}^{-}}$$

这样就能得到每个方案的最后得分了
最后也可以再搞个归一化（也可以不用）

-------------------------

# 6. 拓展
我们在计算距离的时候，默认每个指标的权重是相同的，但实际问题中，各指标的重要程度是不一样的，因此，计算距离可以带上权重

它与最优解的距离
$$d_{i}^{+}=\sqrt{\sum_{j=1}^m\omega_j{\left( Z_{j}^{+}-z_{ij} \right) ^2}}$$
它与最劣解的距离
$$d_{i}^{-}=\sqrt{\sum_{j=1}^m\omega_j{\left( Z_{j}^{-}-z_{ij} \right) ^2}}$$

至于权重怎么确定，有些生活向的可以用层次分析法，更客观一点的方法是熵权法，留到后面
