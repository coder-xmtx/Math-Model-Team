# TOPSIS 算法（优劣解距离法）
## 层次分析法的缺陷
层次分析法有一定缺陷，它的主观性比较大，一般需要专家来进行打分（我们自己也不算专家），而且指标和方案过多时，判断矩阵和一致矩阵可能会出现较大差异（毕竟打分不可能完全遵循那个乘法关系），有具体数据时，再主观打分也不合适

举个例子：
> [!Example] 成绩问题
>
| 姓名     | 高代成绩 | 竞赛得分 | 违纪次数 |
| -------- | -------- | -------- | -------- |
| 小明同学 |          |          |          |
| H.H      |          |          |          |
| Struck   |          |          |          |

$TOPSIS$ 算法的核心思想
> [!Note] TOPSIS 算法
> 根据已有数据 --> 构建所有方案组成的系统中的最优解和最劣解 --> 评价系统中任何一个方案距离最优解和最劣解的综合距离。如果一个方案距离理想最优解越近，距离最劣解越远，我们就有理由认为这个方案更好
