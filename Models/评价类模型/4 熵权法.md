# 熵权法

## 1. 原理
指标的变异程度越小，所反映的现有信息量也越少，其对应的权值也越低。

--------------------------------

## 2. 理解
可以这样理解，越有可能发生的事情发生了，信息量越小；越不可能发生的事情却发生了，信息量越多。我们使用概率衡量时间发生的可能性，同样也可以用概率来衡量事件包含的信息量的大小

#### 2.1 对数函数的形式
信息量用$I$表示，概率用$p$表示，信息量随着概率增大而减小，
概率处于0~1之间，信息量处于0~+∞之间

假设$x$是事件$X$可能发生的某种情况，$p\left(x\right)$表示这种情况发生的概率
定义$I\left( x \right) =-\ln \left( p\left( x \right) \right)$，衡量$x$所包含的信息量
定义域$\left( 0,+\infty \right)$，概率范围$\left( 0,1 \right]$，不考虑概率为0的事件

#### 2.2 信息熵
如果事件$X$可能发生的情况有$x_1,x_2,\cdots,x_n$，则事件$X$的信息熵为
$$H\left( x \right) =\sum_{i=1}^n{\left[ p\left( x_i \right) I\left( x_i \right) \right]}=-\sum_{i=1}^n{\left[ p\left( x_i \right) \ln \left( p\left( x_i \right) \right) \right]}$$
可以看出，信息熵就是对信息量的期望值
==信息熵越大，现有信息量越小==

对于函数 $H\left( x \right)$，当 $p\left( x_1 \right) =p\left( x_2 \right) =\cdots =p\left( x_n \right) =\frac{1}{n}$，$H\left( x \right)$ 取最大值 $\ln \left(n\right)$


#### 2.3 信息熵、现有信息量、潜在信息量
上面说，信息熵是对信息量的期望值，其实是对潜在信息的一种期望。
我们说小概率事件包含的信息量多，是因为一件几乎不可能发生的事情发生了，其背后很大程度上有很多未被发掘的信息，最终导致了小概率事件的发生。
我们说一件大概率事件包含的信息量少，其实也是指这件大概率事件发生后，能够被挖掘出的信息量比较少。

上面未被挖掘的信息量，全部都是事件未发生前的潜在信息量，并不是现有信息量。
当我们已经掌握了足够多的信息，某些事件的发生就是一件自然而然的事情，我们便可以认为这类事件属于大概率事件。
当我们掌握的现有信息较少时，我们很难认为某些事自然状态下会发生，就觉得这类事件是小概率事件。

## 3. 熵权法计算步骤

### 3.1 正向化和标准化，矩阵$Z$
具体方法请看TOPSIS模型的内容

- 如果正向化之后所有数据皆为正数，对于矩阵
$$X=\left( \begin{matrix}
	x_{11}&		x_{12}&		\cdots&		x_{1m}\\
	x_{21}&		x_{22}&		\cdots&		x_{2m}\\
	\vdots&		\vdots&		\ddots&		\vdots\\
	x_{n1}&		x_{n2}&		\cdots&		x_{nm}\\
\end{matrix} \right) $$
我们可以对每一列指标进行标准化

- 如果正向化后的矩阵存在负数，可以用
$$z_{ij}=\frac{x_{ij}-\min \left\{ x_{1j},\cdots ,x_{nj} \right\}}{\max \left\{ x_{1j},\cdots ,x_{nj} \right\} -\min \left\{ x_{1j},\cdots ,x_{nj} \right\}}$$
保证标准化后的数据皆为正数

最后得到标准化的非负矩阵
$$Z=\left( \begin{matrix}
	z_{11}&		z_{12}&		\cdots&		z_{1m}\\
	z_{21}&		z_{22}&		\cdots&		z_{2m}\\
	\vdots&		\vdots&		\ddots&		\vdots\\
	z_{n1}&		z_{n2}&		\cdots&		z_{nm}\\
\end{matrix} \right) $$

### 3.2 计算概率矩阵$P$
计算第$j$项指标下第$i$个样本所占的比重，将其看作信息熵计算中用到的概率，公式如下
$$p_{ij}=\frac{z_{ij}}{\sum\limits_{i=1}^n{z_{ij}}}$$
得到概率矩阵
$$P=\left( \begin{matrix}
	p_{11}&		p_{12}&		\cdots&		p_{1m}\\
	p_{21}&		p_{22}&		\cdots&		p_{2m}\\
	\vdots&		\vdots&		\ddots&		\vdots\\
	p_{n1}&		p_{n2}&		\cdots&		p_{nm}\\
\end{matrix} \right) $$

### 3.3 计算信息熵
对于第$j$个指标而言，信息熵计算公式为
$$e_j=-\frac{1}{\ln n}\sum_{i=1}^n{\left( p_{ij}\cdot \ln p_{ij} \right)},j=\left\{ 1,2,3,\cdots ,m \right\} $$

### 3.4 信息效用值
信息效用值越大，现有信息量越多
$$o_j=1-e_j$$

### 3.5 归一化得到熵权
$$W_j=\frac{o_j}{\sum\limits_{j=1}^m{o_j}}$$

有了权重之后就可以套其他方法了，比如TOPSIS法
熵权法本质上就是**“给包含现有信息量更多的指标以更高的权重”**

---------------------------------------------

## 4. 熵权法局限性
熵权法听着很高端，但仔细想想，也是有一个很严重的bug存在
熵权法仅凭所谓的信息量来获得权重，并不考虑数据的实际意义，很可能得出违背常识的结果

如果对评价指标具有现实性的了解，可以看看熵权法是否符合实际，再决定是否采用。
如果对评价指标了解较少，层次分析法也很难搞，使用熵权法也是无可厚非的事。
